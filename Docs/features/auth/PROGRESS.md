## Sessions

### 2026-05-19
**Goal:** Implement the full auth feature from scratch (Flyway migration through integration tests).

**Completed:**
- `V1__create_users_table.sql` — Flyway migration for the `users` table
- `User` — JPA entity implementing `UserDetails`; UUID PK generated by Hibernate
- `UserRepository` — `findByUsername`, `existsByUsername`
- `UserDetailsServiceImpl` — loads `User` by username for Spring Security
- `JwtTokenService` — generate / validate / parse JWT using jjwt 0.12.6; key derived from raw UTF-8 bytes of `app.jwt.secret`
- `JwtAuthFilter` — `OncePerRequestFilter`; extracts Bearer token, validates, loads user by UUID via `UserRepository`
- `SecurityConfig` — stateless sessions, CSRF disabled, `/auth/**` open, custom `AuthenticationEntryPoint` returning 401
- `AuthService` — `register` (BCrypt hash + persist) and `login` (verify hash + emit JWT)
- `AuthController` — `POST /auth/register` (201) and `POST /auth/login` (200)
- DTOs: `RegisterRequest`, `LoginRequest`, `AuthResponse`, `UserResponse`, `ErrorResponse`
- `UsernameAlreadyTakenException` — maps to 409 in `GlobalExceptionHandler`
- `GlobalExceptionHandler` (`@RestControllerAdvice`) — consistent `{status, error, message}` envelope for validation errors, duplicate username, and bad credentials
- `AuthControllerTest` — all 7 SPEC scenarios pass (full `@SpringBootTest` + MockMvc against live PostgreSQL)

**Decisions made:**
- `User` implements `UserDetails` directly (no separate wrapper) — keeps the class count low; acceptable because only one auth mechanism exists
- JWT filter uses `UserRepository.findById(UUID)` instead of `UserDetailsService.loadUserByUsername` — JWT `sub` is the user UUID, not username; avoids a needless username lookup
- `LoginRequest` has no `@NotBlank` — missing username falls to 401, not 400; avoids leaking which field is wrong
- Custom `AuthenticationEntryPoint` added — Spring Security 7 defaults to 403 for anonymous access; spec requires 401

**Blockers encountered and resolved:**
1. **Spring Boot 4 `@AutoConfigureMockMvc` package moved** → updated import to `org.springframework.boot.webmvc.test.autoconfigure`
2. **Flyway not running** → Spring Boot 4 split Flyway autoconfiguration into a separate `spring-boot-flyway` module; added to `build.gradle.kts`
3. **Native PostgreSQL on port 5432** → remapped Docker container to port 5434 in `docker-compose.yml` and `application.yml`
4. **Spring Security 7 returns 403 for unauthenticated requests** → added explicit `authenticationEntryPoint` to `SecurityConfig`
5. **Port 8081 conflict between test JVM and `bootRun`** → kill lingering test JVM before starting app
